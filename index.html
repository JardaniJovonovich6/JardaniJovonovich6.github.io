Java 25 · Spring Boot · Spring AI · Ollama · MCP

DeviceLens

Repository ↗

The problem

Browser-visible device information and permission states are often difficult to interpret.

The approach

Explain exposed signals locally, with privacy guidance and user-controlled report exports.

Java 21 · Spring Boot · JavaScript · Docker · Render

Architecture & implementation +

SIMPLIFIED FLOW
