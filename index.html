01
BROWSER PRIVACY / LIVE APPLICATION

DeviceLens

What can a website learn about your browser? A privacy inspector that explains the information your browser exposes, permission states, and practical ways to reduce exposure.

Java 21 · Spring Boot · JavaScript · Docker · Render
Check your browser’s privacy ↗
Inside the project +

Explains 38 browser-visible signals across five groups, checks six permission states without requesting access, and offers a privacy checklist and local report exports. Inspection runs in your browser; results are not uploaded to the application server.

See what your browser reveals and review your privacy settings. This is an educational inspector, not a security audit or safety score.

Hosted on Render. The first visit may take a little time to wake up.

AI APPLICATIONS / VALIDATION

VeriCV

A résumé engine built around a simple constraint: generated claims should be grounded in the candidate’s actual experience.

Java · Spring Boot · Spring AI · Ollama · MCP
Inside the project +

Résumé and job-description inputs move through structured JSON, factual validation, targeted repair, and deterministic Markdown/PDF export. A local browser workflow and MCP tools support reusable candidate, job, and result records.

My focus: keeping generation, validation, and export understandable as separate stages.

03
MICROSERVICES / OBSERVABILITY

Commerce Circuit

Order and inventory services, connected through Spring Cloud. A place to investigate what happens when a request crosses service boundaries.

Spring Cloud · OpenFeign · PostgreSQL · Docker · Zipkin
Inside the project +

Separate databases, synchronous stock reduction and restoration, Gateway routing, Eureka discovery, and Git-backed configuration. Experiments cover Resilience4j failure handling, configuration refresh, and tracing with Micrometer and Zipkin.

The ELK/Zipkin guide below documents the local logging and tracing work.

04
SECURITY / TRANSACTIONS

BookHaven

A hotel-booking backend: rooms, availability, pricing, payments, and the transaction boundaries between them.

Spring Security · JWT · Hibernate · PostgreSQL · Stripe
Inside the project +

JWT access and refresh tokens, BCrypt password hashing, and role-based authorization protect booking and administration APIs. Booking and room-inventory flows use transactions, with pricing strategies and Stripe checkout/payment-webhook integration.

Next direction: clearer module boundaries and a more reusable backend.

Kafka · gRPC · Protocol Buffers · Docker · AWS CDK
