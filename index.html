Repository ↗

The problem

An AI-generated résumé can sound convincing while introducing unsupported skills, dates, or claims.

The approach

Separate structured generation, source-grounded validation, targeted repair, and document export.

Java 25 · Spring Boot · Spring AI · Ollama · MCP

Architecture & implementation +

SIMPLIFIED FLOW

Résumé + job→Structured JSON→Validate / repair→Markdown → PDF

What I built

Built a local browser workspace, REST endpoints, and MCP adapters for readable PDF inputs, job context, review, and export. Provider and client-generated workflows use the same validation boundary.

The result

A reviewable résumé draft and requirement analysis, with PDF export when validation and rendering succeed.

Local application. Validation is a safeguard; results still need human review.

05

BROWSER PRIVACY / LIVE APPLICATION

DeviceLens

A closer look at what a website can learn about a browser.

Repository ↗

The problem

Browser-visible device information and permission states are often difficult to interpret.

The approach

Explain exposed signals locally, with privacy guidance and user-controlled report exports.

Java 21 · Spring Boot · JavaScript · Docker · Render

Architecture & implementation +

SIMPLIFIED FLOW

Browser signals→Local inspection→Explained readings→Local export

What I built

Explains 38 browser-visible signals and checks six permission states without requesting the underlying access. Inspection results remain in the browser; Spring Boot serves the interface.

The result

A public application visitors can try, with repeatable inspection and local JSON/text exports.

An educational privacy inspector, not a security audit or safety score. Render may take time to wake up.
